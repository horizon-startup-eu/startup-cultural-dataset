# Changelog

All notable changes to this dataset will be documented in this file.

Versioning follows: MAJOR (schema breaks), MINOR (cities/fields added), PATCH (record corrections).

## [1.0.0] - 2026-11-12

### Initial release

- 2112 cultural places across 8 European cities/regions
- Cities: Dortmund/Bochum/Gelsenkirchen (Ruhr), Madrid, Stockholm, Rome, Gdansk, Sevilla, Trencin, Eurometropole de Strasbourg
- Source: Overture Maps Foundation places theme (release 2025-05-21.0) + locally curated submissions
- Boundaries: Eurostat GISCO LAU 2024, Etalab EPCI
- Formats: GeoJSON, CSV
- CRS: WGS84 (EPSG:4326)
